# Screenshots — real evidence only

This directory is for **real screenshots of the running ReceiptReader app**, not generated mockups presented as a deployed product. At repository audit time there was no verified committed app screenshot.

Suggested files after sanitization:

- `01_upload.png` — live Streamlit image upload and preview.
- `02_review_four_fields.png` — real OCR and four candidate fields with an **illustrative/synthetic receipt**, identified as a **single smoke test**.
- `03_export_confirmed.png` — confirmation and actual JSON/CSV download actions.
- `04_failure_review.png` — a real error or abstention demonstrating human correction, if tested.

Caption each image with commit SHA, app mode (`Tesseract PSM 6 heuristic baseline`), test date, source/rights and whether the content is synthetic, sanitized, or licensed. Blur personal data, order identifiers and phone numbers from real receipts. Never place sensitive exports beside screenshots. No screenshot by itself supports an accuracy claim.
